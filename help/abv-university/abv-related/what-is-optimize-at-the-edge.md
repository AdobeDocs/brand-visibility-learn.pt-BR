# O que é otimizar na Edge?

Otimizar o nos sites do Edge em seu CDN e retorna uma versão pré-renderizada de sua página para bots de IA, para que eles possam ver o conteúdo oculto atrás do JavaScript do lado do cliente, sem impacto nos usuários.

## Para quem é este vídeo?

* Administradores e usuários que melhoram o quanto os bots de IA de uma página podem visualizar
* Equipes com conteúdo renderizado no lado do cliente ou páginas de comércio eletrônico

## Conteúdo de vídeo

Neste vídeo, você aprenderá:

* O que significa &quot;na borda&quot;: sentar na camada de CDN entre a Web e o site
* Por que os bots de IA geralmente perdem conteúdo renderizado no lado do cliente, como preços
* Como a oportunidade de visibilidade do conteúdo de recuperação é implantada com um único clique
* Como o HTML pré-renderizado é distribuído somente para bots de IA, não para usuários
* Como os resumos e os sumários inseridos ajudam os bots a entender uma página
